# Detection Rules

## Rule 1 — Multiple Failed Logins
Trigger alert after 5 failed logins within 10 minutes.

## Rule 2 — Privilege Escalation
Alert when a user is granted admin privileges unexpectedly.

## Rule 3 — Disabled MFA
Alert when MFA is disabled for any account.

## Rule 4 — Suspicious Network Traffic
Alert on outbound traffic to unknown IP ranges.

## Rule 5 — Service Account Misuse
Alert when service accounts perform human-like actions.
