# Logging & SIEM Pipeline

## Overview
This project demonstrates a cloud-aligned logging and SIEM pipeline used for compliance, monitoring, and incident detection. It shows how logs flow from systems to a SIEM, how alerts are generated, and how compliance visibility is maintained.

## Purpose
Compliance frameworks require centralized logging, monitoring, and alerting. This project demonstrates:
- Log ingestion
- Normalization
- Alerting
- Detection rules
- Compliance visibility
- Incident response alignment

## Included Files
- log-sources.md — List of log sources and retention requirements
- detection-rules.md — Sample SIEM detection rules
- compliance-mapping.md — Mapping to HIPAA, SOC2, ISO27001

## Skills Demonstrated
- Monitoring & detection
- Compliance visibility
- SIEM fundamentals
- Incident response alignment
