# Log Sources

## Identity Logs
- Login attempts
- MFA events
- Privilege escalations

## Network Logs
- Firewall events
- VPC flow logs
- VPN access logs

## Application Logs
- Errors
- Authentication failures
- API calls

## System Logs
- OS events
- Process starts/stops
- Configuration changes

## Retention Requirements
- HIPAA: 6 years
- SOC2: 1 year minimum
- ISO27001: Based on risk assessment
